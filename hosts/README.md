## Host Directory Structure

Each host directory (`hosts/<hostname>/`) adheres to a standard layout:

```text
hosts/<hostname>/
├── default.nix                 # Main host entry point
├── hardware-configuration.nix  # Auto-generated hardware configuration (do NOT edit manually)
├── disko.nix                   # Partitioning, filesystems (Btrfs), and boot decryption (TPM2/LUKS)
├── config.nix                  # (Optional) Host-specific module options and agenix secrets
└── flatpak.nix                 # (Optional) Host-specific Flatpak packages (auto-imported by modules/flatpak)
```

### File Responsibilities

1. **`default.nix`** ([framework16](./framework16/default.nix), [mini-pc-k8](./mini-pc-k8/default.nix), [legion-go](./legion-go/default.nix)):
   The primary entry point imported by `outputs.nix`. Simply imports `disko.nix`, `hardware-configuration.nix`, and optionally `config.nix`.

2. **`hardware-configuration.nix`** ([framework16](./framework16/hardware-configuration.nix), [mini-pc-k8](./mini-pc-k8/hardware-configuration.nix), [legion-go](./legion-go/hardware-configuration.nix)):
   Auto-generated by `nixos-generate-config` or during `install.sh`. Ignore any linter warnings inside this file and never manually modify it.

3. **`disko.nix`** ([framework16](./framework16/disko.nix), [mini-pc-k8](./mini-pc-k8/disko.nix), [legion-go](./legion-go/disko.nix)):
   Defines the complete block storage lifecycle:
   * Partition tables (GPT, ESP `/boot`).
   * Disk encryption (LUKS containers and optional TPM2 auto-unlock via `crypttabExtraOpts`).
   * Filesystem formatting and subvolumes (Btrfs root, home, nix, swap).
   * Storage maintenance timers (`services.btrfs.autoScrub`).

4. **`config.nix` (Optional)** ([framework16](./framework16/config.nix), [mini-pc-k8](./mini-pc-k8/config.nix), [legion-go](./legion-go/config.nix)):
   A consolidated module for any machine-specific option toggles (e.g. `custom.ai`, `custom.vpn.wireguard`) and host-specific secrets (`age.secrets`). Avoid creating micro-files for individual feature toggles.

5. **`flatpak.nix` (Optional)**:
   A dedicated list of machine-specific Flatpak packages and sandbox overrides, auto-discovered and imported by [`modules/flatpak/`](../modules/flatpak) if present.

## Connection to `outputs.nix`

Every host is declared in the `hosts` set in [`outputs.nix`](../outputs.nix):

```nix
<hostname> = {
  username = "<user_name>";
  system = "x86_64-linux";

  extraModules = [
    # Host-specific NixOS system modules (e.g. nixos-hardware, profiles/laptop, profiles/desktop, profiles/gaming-handheld)
  ];
};
```

## Host Profiles & Hardware Details

### 1. `framework16` (Primary Workstation Laptop)
* **Hardware**: AMD Ryzen 7 7040 series (Phoenix, 8C/16T, Zen 4, Radeon 780M).
* **Storage & Encryption**: LUKS full disk encryption on Btrfs with TPM2 auto-unlock (`crypttabExtraOpts` against PCR 7) and Lanzaboote UEFI Secure Boot cryptographic signing.
* **Hibernation**: Configured with a dedicated swapfile sized for RAM capacity + 2–4 GB buffer for hibernation and sleep transitions (`suspend-then-hibernate`).
* **Profile**: Imports [`profiles/laptop`](../modules/profiles/laptop), [`modules/framework`](../modules/framework), and [`modules/lanzaboote`](../modules/lanzaboote).

### 2. `mini-pc-k8` (Living Room HTPC / Desktop)
* **Hardware**: GMKtec K8, AMD Ryzen 7 8845HS (Hawk Point, 8C/16T, Zen 4, Radeon 780M).
* **Storage**: Unencrypted Btrfs with automated monthly scrub timers.
* **Profile**: Imports [`profiles/desktop`](../modules/profiles/desktop) and [`modules/power-management/ppd.nix`](../modules/power-management/ppd.nix).

### 3. `legion-go` (Handheld Gaming Console)
* **Hardware**: AMD Ryzen Z1 Extreme (Phoenix, 8C/16T, Zen 4, Radeon 780M, NPU fused off).
* **Storage & Partitioning**:
  * Unencrypted Btrfs on `/dev/nvme0n1` with subvolumes for `/root`, `/home`, `/nix`, and a 20 GB swapfile (`/.swap/swapfile`) supporting 16 GB LPDDR5X RAM hibernation (`suspend-then-hibernate`) + paging.
  * **Design Rationale**: A keyboardless gaming handheld avoids LUKS early-boot passphrase entry friction and eliminates dm-crypt context-switching overhead on the APU power budget.
* **Display Hardware Quirk**:
  * The 8.8" QHD+ (2560x1600 144Hz) internal display is manufactured in native portrait scanout (`1600x2560`, `DRM_MODE_PANEL_ORIENTATION_LEFT_UP`).
  * Rotated right-side up at early boot in `hosts/legion-go/config.nix` via kernel parameters:
    ```nix
    boot.kernelParams = [
      "video=eDP-1:panel_orientation=right_side_up"
      "fbcon=rotate:1"
    ];
    ```
  * Gamescope compositing arguments rotate the session display cleanly: `--force-orientation left`, `--force-composition-rotation`, `-w 2560 -h 1600 -W 2560 -H 1600 -r 144 --prefer-output eDP-1`.
* **Controllers & Connectivity**:
  * TrueStrike controllers, gyro aiming, optical mouse sensor, and TDP curves managed by Handheld Daemon (`services.handheld-daemon.adjustor.enable = true`).
  * `custom.wireless.bluetooth.powerOnBoot = true` ensures detached controllers and wireless headsets reconnect upon boot.
* **Profile**: Imports [`profiles/gaming-handheld`](../modules/profiles/gaming-handheld).

## Conventions & Rules
* **No hardcoded paths or IDs**: Use dynamic `username` and the standard `users` group. Avoid hardcoded `/home/<username>` paths; reference `specialArgs.username` or config variables.
* **Keep it host-specific**: Generic or reusable capabilities belong in [`modules/`](../modules) or [`home/`](../home).
* **Per-host user configuration**: All baseline user configurations are imported directly from [`home/`](../home); host-specific user additions belong in `hosts/<hostname>/home/` (automatically imported if present).
